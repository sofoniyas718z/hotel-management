# 🏨 Hotel Booking Management System

A web-based **Hotel Booking Management System (HBMS)** developed as a final-year Computer Science project. The system helps centralize hotel operations such as reservations, guest management, room management, housekeeping, billing, and payments.

## ✨ Features

- 🛏️ Room and room-availability management
- 📅 Online booking and reservation management
- 👤 Guest registration and profile management
- 🏨 Check-in and check-out management
- 🧹 Housekeeping task management
- 💳 Billing and payment processing
- 👥 Customer and staff management
- 🔐 Role-based access control
- 📊 Administrative dashboards and reports
- 📝 Booking history and management

## 🛠️ Technology Stack

**Frontend**
- React
- TypeScript
- Vite
- Tailwind CSS

**Backend**
- PHP
- MySQL
- REST-style API

**Payment Integration**
- Chapa
- Telebirr
